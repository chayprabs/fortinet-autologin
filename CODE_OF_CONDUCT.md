# Code of conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, no harassment. Report problems to the
maintainer through a private
[security advisory](https://github.com/chayprabs/fortinet-autologin/security/advisories/new)
or by email via the GitHub profile.
