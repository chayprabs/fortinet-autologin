# fortinet-autologin

Stay logged in to a FortiGate captive portal (college / office Wi-Fi) without
babysitting it.

FortiGate portals kick you out on a hard timer (often 14400 s = 4 hours) and
make you log in again. Downloads die, SSH drops, long jobs stall. This tool
watches for that and logs you back in within a couple of seconds.

Work in progress.
